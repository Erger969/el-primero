 PUNTO 1: CONFIGURACIÓN INICIAL DEL PROYECTO

1.1 Creación del proyecto Laravel
• [ ] 1.1.1 Ejecutar composer create-project laravel/laravel red-social-universitaria
• [ ] 1.1.2 Verificar que Laravel 12 esté instalado (php artisan --version)
• [ ] 1.1.3 Configurar archivo .env con conexión a XAMPP (MySQL)
• [ ] 1.1.4 Ejecutar php artisan serve y probar que la página de bienvenidafuncione

1.2 Instalación de paquetes necesarios
• [ ] 1.2.1 Instalar Laravel Breeze (autenticación): composer require laravel/breeze--dev
• [ ] 1.2.2 Ejecutar php artisan breeze:install blade
• [ ] 1.2.3 Instalar npm install y npm run build
• [ ] 1.2.4 Instalar paquete para Cloudinary: composer require cloudinarylabs/cloudinary-laravel
• [ ] 1.2.5 Instalar Spatie Laravel Permission (opcional, pero útil para roles): composer require spatie/laravel-permission

1.3 Configuración de Git y GitHub

• [ ] 1.3.3 Crear rama develop para desarrollo conjunto
